Markdown Formatting Guide

# Heading Creates a heading (# to ###### for different levels)
**bold** Makes text bold
*italic* Makes text italic
~~strikethrough~~ Creates strikethrough text
`code` Creates inline code
```language
code block
```		 Creates a syntax-highlighted code block
- item Creates a bullet list
1. item Creates a numbered list
[link](url) Creates a hyperlink
![alt](image-url) Inserts an image
> quote Creates a blockquote
--- Inserts a horizontal rule
==highlight== Highlights text
